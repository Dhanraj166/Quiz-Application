
Quiz Application
A modern, interactive Quiz Application built with React that allows users to test their knowledge across multiple categories with real-time feedback and results.
Live Demo:

https://quiz-application-tawny-zeta.vercel.app

 Features
·	 Multiple quiz categories
·	⏱ Real-time score calculation
·	 Progress bar for quiz completion
·	 Instant feedback on answers
·	 Detailed results summary
·	 Restart quiz option
·	 Fully responsive design (mobile & desktop)

 Tech Stack
·	React 18
·	JavaScript (ES6+)
·	Vite
·	CSS
·	Context API

React Concepts Used
·	useState – Component state management
·	useEffect – Side effects & lifecycle handling
·	useContext – Global state management
·	React Router DOM
o	BrowserRouter
o	useNavigate
·	Component-based architecture

 How It Works
1.	User enters their name
2.	Starts the quiz
3.	Answers multiple-choice questions
4.	Progress bar updates in real time
5.	Final score and detailed results are displayed

Installation & Setup
To run this project locally:
git clone https://github.com/Dhanraj166/Quiz-Application.git
cd Quiz-Application
npm install
npm run dev

Open: http://localhost:5173

 Deployment
The application is deployed on Vercel with automatic deployments enabled.
·	Any push to the main branch triggers a new deployment
·	Fast builds and global CDN support
